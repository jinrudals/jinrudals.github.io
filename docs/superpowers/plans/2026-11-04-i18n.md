# i18n Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Serve the SvelteKit site in Korean (default, `/`) and English (`/en/...`) with browser-language auto-redirect and a persistent toggle.

**Architecture:** Optional route param `[[lang=lang]]` wraps every route; a hand-rolled `i18n.ts` holds the dictionary and pure path helpers; markdown posts are `slug.md` / `slug.en.md` with Korean fallback; detection is an inline client script (static hosting).

**Tech Stack:** SvelteKit 2, Svelte 5, mdsvex, adapter-static, Node built-in test runner (Node 24 strips TS types), Playwright (already installed).

**Spec:** `docs/superpowers/specs/2026-11-04-i18n-design.md`

## Global Constraints

- Languages: `ko` (default, served at `/`), `en` (served at `/en/...`).
- No new runtime or dev dependencies.
- Auto-detection is client-side only.
- Unknown dict key falls back to ko, then to the key itself.
- Untranslated post under `/en/` renders the Korean original with a "Korean original" notice; the English list shows only posts that have an English file.
- Commits: Angular-style conventional commits, with the `Co-authored-by: Copilot <223556219+Copilot@users.noreply.github.com>` trailer. Work only in the `.worktrees/i18n` worktree on `feat/i18n`.
- Run `npm run check` before each commit; run `npm install` first if `node_modules` is missing in the worktree. Mermaid needs `npx playwright install chromium` for `npm run build`.

## Review Focus

- Visitor on `/en/` with stored `lang=ko` is sent to the Korean path (not looped).
- `/en` and `/en/` (root) toggle correctly to `/` and back; trailing slashes and nested `/writing/slug` paths map correctly.
- English post missing → `/en/writing/<slug>` shows Korean body plus notice, never 404.
- Frontmatter-less or draft English file is excluded from the English list.
- Prerender must not fail on `[[lang=lang]]` with an empty `entries` content set (no posts exist today).

## File Structure

- Create `src/params/lang.ts` — matcher, `en` only.
- Create `src/lib/i18n.ts` — `Lang`, `dict`, `t`, `localePath`, `switchPath`, `detectRedirect`.
- Create `src/lib/i18n.test.ts` — node tests for the pure functions.
- Create `src/lib/content-select.ts` + `src/lib/content-select.test.ts` — pure file-name/selection logic.
- Modify `src/lib/content.ts`, `src/lib/career.ts`, `src/lib/Article.svelte`, `src/lib/EntryList.svelte`, `src/app.html`, `src/routes/+layout.svelte`, `src/routes/+layout.ts`.
- Move every other `src/routes/*` page into `src/routes/[[lang=lang]]/` (`git mv`) and localize its copy.
- Modify `package.json` — add `"test": "node --test src/lib/*.test.ts"`.

### Task 1: i18n core and matcher

**Files:**
- Create: `src/params/lang.ts`, `src/lib/i18n.ts`, `src/lib/i18n.test.ts`
- Modify: `package.json` (add `test` script)

**Interfaces:**
- Produces:
  - `export type Lang = 'ko' | 'en'`
  - `export const dict: Record<Lang, Record<string, string>>`
  - `export function t(lang: Lang, key: string): string`
  - `export function localePath(lang: Lang, path: string): string` — `('en','/writing')→'/en/writing'`, `('ko','/writing')→'/writing'`, `('en','/')→'/en'`.
  - `export function switchPath(pathname: string, to: Lang): string` — strips a leading `/en` segment then applies `localePath(to, …)`; `('/en', 'ko')→'/'`, `('/en/writing/a/','ko')→'/writing/a/'`, `('/writing','en')→'/en/writing'`.
  - `export function detectRedirect(args: { pathname: string; stored: string | null; browser: string }): string | null` — returns target path or `null`. `stored` wins when set (`'ko'`/`'en'`); otherwise `browser.toLowerCase().startsWith('en')` → `en`, else `ko`. Returns `switchPath(pathname, wanted)` only if it differs from `pathname`.
  - `export const match: ParamMatcher` in `src/params/lang.ts` returning `param === 'en'`.
